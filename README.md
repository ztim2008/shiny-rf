# Шины РФ — прототип каталога

Статический прототип каталога шин: главная с каталогом и отдельная корзина. Бренд «Шины РФ» и подпись «Прототип каталога» — нейтральные заглушки. Телефон, адрес, MAX и Telegram не заданы: кнопки связи подписаны как прототип и никуда не ведут.

В каталоге 16 демо-позиций: легковые, коммерческие и грузовые шины, лето и зима. Модель указана только если она читается на фото или в подписи источника. Цены в рублях — образец каталога, не предложение магазина. Кнопка «Оформление заказа — демо» не создаёт заказ.

Фотографии лежат в `assets/img/` (JPEG и WebP). Источники, авторы и лицензии — в [ASSET_SOURCES.md](ASSET_SOURCES.md).

## Локальный просмотр

Ссылки внутри сайта относительные, поэтому страницы открываются и как файлы, и с локального сервера. Общая корзина между `index.html` и `cart.html` надёжно работает через сервер: оба адреса тогда в одном origin, и `localStorage` общий.

Из корня репозитория:

```bash
python3 -m http.server 4179
```

Дальше откройте `http://127.0.0.1:4179/`.

## Публикация на GitHub Pages

Сайт рассчитан на корень репозитория и на адрес вида `https://<user>.github.io/<repo>/`.

1. Положите содержимое этого репозитория в ветку `main` (файлы в корне, не в подпапке `docs`).
2. В настройках репозитория откройте Pages и выберите ветку `main`, папку `/ (root)`.
3. Не добавляйте телефон, имя в мессенджере или внешние картинки вместо локальных файлов, пока это не настоящие данные магазина.

Сборка не нужна: это обычные HTML, CSS и JS.
